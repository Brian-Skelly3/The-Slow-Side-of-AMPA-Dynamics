# The-Slow-Side-of-AMPA-Dynamics

Accompanying code and data for research paper, "The slow side of AMPA DYnamics: A Parsimoneous framwork for TARP-dependant receptor dynamics"

"General_Analysis" explains how the synaptic models are defined and utilised. This file provides the majority of the analysis.

"Optimisationi_Analysis" focuses purely on how well the optimisation process performs.

"Parameter_Analysis" details how the model responds to changes in the parameters.

"1neur1recep.py" is for simulating the single neuron Hodgkin-Huxley data.

"Import_KineticModelBuiledr_Data.ipynb" is used for importing the Monte Carlo ismulation data and plotting against the deterministic model data.
